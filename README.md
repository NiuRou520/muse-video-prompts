# muse-video-prompts

Muse Video 提示词库：可搜索、可按类筛选、可一键复制的视频提示词集合。

- **目标**：204 条，覆盖 13 类（自拍 / Vlog日常 / 转场 / 古风 / ASMR / 电影感剧情 / 产品广告 / 旅行风光 / 宠物动物 / 美食 / 科幻未来 / 运动活力 / 治愈日常）
- **当前**：65 条种子（每类 5 条），由「AI 视频工作流空间」整理编写，持续扩充至 204 条
- **格式**：`prompts.json`（机器可读，空间同步用）+ `templates.md`（模板句式）

## 文件

| 文件 | 说明 |
| --- | --- |
| `prompts.json` | 全部提示词：id、分类、标题、中文提示词、英文提示词、作者、来源 |
| `templates.md` | 模板句式：镜头简报、运动模式、视听工作流 |

## 字段说明

每条提示词：

```json
{
  "id": "zp01",
  "cat": "自拍",
  "title": "晨光窗边自拍",
  "cn": "中文提示词……",
  "en": "English prompt……",
  "author": "空间整理",
  "source": "站内原创"
}
```

- `author` 为真实作者名；`source` 为原帖链接（有的话）或 `站内原创`。
- 不要编造作者与链接：没有来源的条目标 `站内原创`，由空间原创整理。

## 如何扩充到 204 条

1. 在 `prompts.json` 的 `prompts` 数组里按格式追加，`id` 按分类前缀 + 序号（如 `zp06`）。
2. 或在「AI 视频工作流空间」的提示词库里新建，导出 JSON 后合并进来。
3. 提交时说明新增条数与分类，保持每类数量均衡。
